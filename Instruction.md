# ZigZag — lounge bar, Королёв

Одностраничный сайт, построенный вокруг одной трёхмерной модели кальяна.
Камера облетает модель на 354° по мере прокрутки: шесть «глав», каждая —
своя точка съёмки, свой свет и своя плотность дыма.

**Реквизиты заведения:** пр-т Космонавтов, 36Б, Королёв · +7 977 311‑12‑06 ·
[vk.ru/zigzag_korolev](https://vk.ru/zigzag_korolev)

## Запуск

```bash
npm install
```

```bash
npm run dev
```

Дев-сервер поднимется на `http://localhost:5183`.

```bash
npm run build
```

Готовый статический сайт складывается в `dist/` — его можно положить на любой
статический хостинг: Netlify, Vercel, GitHub Pages, Timeweb, обычный nginx. Бэкенд не нужен.

```bash
npm run preview
```

Локальная проверка собранной версии на `http://localhost:4173`.

## Что где лежит

```
index.html              вся текстовая часть сайта + SEO-разметка (Schema.org)
src/
  main.js               загрузка: прелоадер → сцена → скролл → интро
  scroll.js             хореография камеры: 6 кадров, сплайн и пружина
  ui.js                 прелоадер, мобильное меню, мелочи
  styles.css            дизайн-токены и вся вёрстка
  three/
    world.js            рендерер, свет, зеркальный пол, пост-обработка, цикл
    hookah.js           процедурная модель кальяна (профили тел вращения)
    env.js              студийное освещение (PMREM) и градиентный задник
    atmosphere.js       дым и угольки — два GPU-партикла
    grade.js            финальный грейд: зерно, виньетка, аберрация
    textures.js         текстуры, нарисованные на canvas (шланг, дым, пол)
```

Модель **не загружается файлом** — она целиком описана профилями в
`src/three/hookah.js`. Поэтому сайт не тянет ни одного мегабайта геометрии,
а пропорции меняются правкой пары чисел.

## Как править контент

**Тексты, телефон, адрес** — прямо в `index.html`. Телефон встречается в
четырёх местах: шапка, мобильное меню, карточка контактов и блок `application/ld+json`
в `<head>` (эта разметка нужна поисковикам — её тоже стоит обновить).

**Часы работы** — секция `#visit`, карточка «Часы работы». Сейчас там стоит
«Ежедневно · точное время уточняйте по телефону»: реальный график на VK-странице
не опубликован, поэтому конкретные часы не выдуманы. Как только заведение назовёт
режим работы — впишите его туда и в `openingHours` в Schema.org-разметке.

**Цены** не указаны намеренно: актуального прайса в открытых источниках нет.
Если нужен раздел с ценами — он логично встаёт четвёртой главой, рядом с баром.

## Как править 3D

**Кадры камеры** — массив `KEYS` в `src/scroll.js`. Одна строка = одна глава.
Между кадрами значения идут не по отрезкам, а по сплайну Catmull-Rom: скорость
камеры непрерывна и на самих главах тоже, поэтому облёт не «клюёт» на каждой
секции. Сплайн проходит ровно через заданные значения — правка числа в таблице
меняет ровно тот кадр, который вы правите. За камерой следит критически
демпфированная пружина (`SMOOTH_TIME`), она даёт вес и плавный разгон.

| поле | что делает |
|------|-----------|
| `radius` | расстояние до модели |
| `theta` | угол облёта в радианах (растёт от главы к главе — это и есть облёт) |
| `phi` | наклон: `0` — точно сверху, `1.57` — на уровне глаз, больше — снизу |
| `ty` | высота точки, на которую смотрит камера (`0` — пол, `6.5` — угли) |
| `fov` | угол объектива |
| `offX` | сдвиг модели по горизонтали: `+` — влево, `−` — вправо от текста |
| `smoke` / `bloom` / `exposure` | плотность дыма, свечение, экспозиция |

**Пропорции кальяна** — константы `P_VASE`, `P_STEM`, `P_BOWL`, `P_HMD` и др.
в `src/three/hookah.js`. Каждая — список точек `[радиус, высота]`, из которых
вращением строится деталь. Единица ≈ 8 см, полная высота ≈ 6.6.

**Свет** — `src/three/env.js` (отражения в стекле и металле) и блок `lights`
в `src/three/world.js` (тени и объём).

## Производительность и доступность

- Вес: ~150 КБ gzip на всю страницу вместе с three.js. Ни одной внешней текстуры.
- На телефонах и слабых машинах автоматически: меньше сегментов геометрии,
  меньше частиц, без теней и зеркального пола, ниже разрешение рендера.
  Если первые секунды идут ниже 40 fps — разрешение снижается ещё раз.
- Вкладка в фоне — цикл рендера останавливается.
- `prefers-reduced-motion` — плавная прокрутка, зерно и параллакс отключаются,
  камера следует за скроллом без инерции.
- Без WebGL страница остаётся рабочей: канвас скрывается, включается
  нарисованный CSS-фон, весь текст и контакты на месте.
- Канвас помечен `role="img"` с описанием, есть skip-link, видимый фокус
  на всех интерактивных элементах, контраст текста выше 4.5:1.

   первого экрана; положить в `public/og.jpg` и добавить мета-тег.
3. **Домен и аналитика** — заменить `https://zigzag-korolev.ru/` в `<link rel="canonical">`
   на реальный адрес, подключить Яндекс.Метрику.
4. **Форма брони** — сейчас CTA ведёт на звонок. Если нужна форма,
   её место — в секции `#visit`.
